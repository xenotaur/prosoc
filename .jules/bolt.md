## 2024-05-16 - Pre-compile jsonschema for performance\n**Learning:** When using `jsonschema` for validation, top-level `jsonschema.validate(instance, schema)` in loops or hot paths is a bottleneck because it recompiles the schema on every call, and parsing from JSON every time adds overhead.\n**Action:** Use `jsonschema.validators.validator_for(schema)(schema)` to pre-compile the schema, and use `@functools.lru_cache` to cache schema parsing and compilation so they are only done once.
